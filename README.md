# Sadeen AK | Chaotic Art Studio Portfolio

A custom-built, dynamic web portfolio designed to showcase the multidisciplinary artwork of Sadeen AK. The site features a bespoke "Deep Ink" dark-mode aesthetic, vibrant neon UI accents, and fluid masonry galleries that display artwork seamlessly without cropping.

## Features
* **Deep Ink Design System:** Dark backgrounds (`#0F0E14`) with high-contrast core text (`#F4F2ED`), accented by interactive glowing Pink (`#FF6EF5`) and Blue (`#9BD3F8`) UI elements.
* **Uncropped Masonry Galleries:** A pure CSS multi-column layout that accommodates both portrait and landscape artwork in their original aspect ratios.
* **Chaotic Neon UI:** Interactive hover states, glowing image overlays, and stylized, layered graphic frames that break the traditional corporate grid.
* **Clean URL Architecture:** Organized directory routing using nested `index.html` files for clean, professional links (e.g., `/illustrations/` instead of `/illustrations.html`).
* **Responsive Design:** Fully optimized for mobile, tablet, and desktop viewing.

## Site Structure
The portfolio is organized into six primary artistic categories:
* 🎬 Animations
* 🎮 Game Development
* 🖌️ Graphic Design
* 🎨 Illustrations
* 📷 Photography
* 🧵 Traditional Crafts

## Tech Stack
* **HTML5** 
* **CSS3** (Custom Grid/Flexbox layouts, CSS Variables, Native CSS Masonry)
* **Vanilla JavaScript** 

## Local Development
To run this project locally:
1. Clone the repository:
   ```bash
   git clone https://github.com/habukhalaf/sadeen-ak-portfolio.git
   ```
2. Navigate to the project directory:
   ```bash
   cd sadeen-ak-portfolio
   ```
3. Open the main `index.html` file in your preferred web browser, or use a local development server (like VS Code's Live Server extension) to ensure the nested folder routing works perfectly.

## Deployment
This portfolio is optimized for static hosting and is deployed directly via **GitHub Pages**.
